# Java DSA Practice (`java-coding`)

This repository contains Data Structures and Algorithms (DSA) and Object-Oriented Programming (OOP) problems solved independently in **Java** from scratch.

## Folder Structure
* **01-Basics-and-Patterns** – Loops, basic math, and pattern printing
* **02-Arrays** – 1D/2D array traversal, searching, and matrix manipulation
* **03-Strings** – String parsing and character manipulation
* **04-Bit-Manipulation** – Bitmasking, binary counting, and number system conversions
* **05-Recursion-and-Backtracking** – Recursive call-stack tracing and backtracking puzzles
* **06-Linked-List** – Custom node implementations and pointer operations
* **07-Sorting-and-Searching** – Divide-and-conquer sorting algorithms
* **08-Object-Oriented-Programming** – Classes, objects, attributes, and methods


## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/JananiAppachi/java-coding
   ```
2. Navigate to any topic folder, compile, and run:
   ```bash
   javac FileName.java
   java FileName
   ```
